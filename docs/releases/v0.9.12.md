**Early alpha: an ad blocker for the whole network.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.12
- **Ad blocker** (Apps > **Ad blocker**, or the `adblock` command). This computer becomes a small DNS server (dnsmasq) that answers "no such address" for the names of known ad and tracker servers, so devices that use it never load them: every browser, phone and smart TV on your network, with nothing to install on them.
  - **S** switches it on (the first time it installs the DNS server and downloads a well-known community list of ad and tracker servers; the computer must be online) and off. **U** updates the list.
  - **Use it:** set this computer's address as the **DNS server** in your router's settings (then every device on the network uses it), or on one phone or PC only. Give the router a second, normal DNS server as a backup, so that the internet keeps working when this computer is off.
  - **A** allows a name that a site needs (the name and its subdomains are never blocked again until you press **D**), **C** checks whether a name is on the list.
  - Everything else is passed on to the DNS servers the computer already uses. The firewall opens port 53 for your **home network only**.
  - Some ads come from the same server as the page itself (many video ads) and cannot be blocked this way.
- **Command:** `adblock on | off | update | allow NAME | unallow NAME | check NAME | status`.
- Plus everything from v0.9.11 (Tailscale fix), v0.9.10 (Tailscale, importing a Minecraft server), v0.9.9 (`passwd`), v0.9.8 (photo gallery), v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).

### Still missing
Databases, print server, more game servers, scheduled backups, a full user management screen, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
