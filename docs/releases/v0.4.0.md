**Early alpha: the apps are here.** Install it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.4.0
Open apps from the **Apps** menu (Alt+A). They tile next to the file browser, never overlapping; F6 switches window, F4 closes one.
- **Explorer**: new file / new folder / rename / delete / copy / cut / paste, with confirmations.
- **Notepad** (save, find), **Terminal (Cmd)** (a real shell in a window), **Paint**, **Calculator**,
  **Clock and calendar**, **System monitor** (end a process with K), **Disk usage**, **Network** (status; settings come later),
  and the games **Reversi** and **Snake**. Light/dark applies to all of them.
- The network is brought up automatically (DHCP on wired connections).

### Still missing
Service manager, software installer, changing network settings from the Network app, Wi-Fi, accented letters (shown as a box).

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer** (the installed system uses about 150 MB idle in the test VM).

### Try it
See the v0.3.0 notes for the QEMU commands (use `exec85-v0.4.0.iso`). Check the download with `sha256sum -c SHA256SUMS`.
