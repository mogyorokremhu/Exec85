**Early alpha: the whole Exec85 screen in a web browser.** For a server in the garage. Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.5
- **Browser access** (Apps > **Remote access**, press **W**, or `webaccess on`). Open `https://<the server's address>:8443` on Windows, Mac or a phone, log in with your Exec85 user name and password, and you get **your own Exec85 desktop**: the file manager, editor, terminal, Minecraft server, services, updates, everything the laptop's own screen can do. It is a separate session (the laptop's screen is not mirrored or taken over).
- **Phones:** a row of on-screen buttons (Esc, Tab, arrows, Enter, F-keys, Apps and Menu, sticky Ctrl and Alt) and the phone's own keyboard. Landscape is nicer.
- **Files in the browser:** the **Files** button sends files from your computer to the server (or drag and drop them onto the page) and fetches files from it. Files are read and written with *your* rights, never more, and an existing file is never overwritten.
- **Safe by design:** it is **off until you switch it on**. Everything is encrypted (HTTPS). Your browser will warn once that the certificate is not trusted: it was made by the server itself. Click "Advanced" and continue (the Remote access screen shows the certificate's fingerprint so you can compare it). Root cannot log in. Five wrong passwords lock that name (and that address) for five minutes. Sessions end after 30 minutes without a key press. The firewall opens the port for your **home network only**.
- **From outside your home:** add a TCP tunnel for port **8443** to your local address `127.0.0.1` in the playit.gg dashboard (the same agent as for Minecraft) and open the address playit.gg gives you. Use a strong password; anyone who can reach the address can try to log in.
- **Paper servers no longer crash when somebody joins.** Paper brings network and compression libraries built for another Linux C library than Exec85's, and Java crashed (SIGSEGV) at the first login, then the server restarted by itself. All Minecraft servers now start with two Java options that switch those libraries off, and servers you already have get the options too (restart them once). CI now starts a real Paper server and logs in to it with a small test client, both unencrypted (compression) and encrypted (online mode), and checks that Java stays up.
- Plus everything from v0.9.4. Updates from v0.9.4 work in place: after the update, `webaccess on` downloads two small programs (stunnel and openssl) the first time.

### Known limits
- The browser screen has no mouse (Exec85 is keyboard driven, like the real screen).
- Browser access cannot show the physical screen or the installer; it is for an installed system.

### Still missing
Databases, print server, more game servers, scheduled backups, user management, scheduled tasks; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
