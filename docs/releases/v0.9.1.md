**Early alpha: the install disc now really starts the installed system, and a Minecraft server list.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.9.1
- **Install disc left in the drive (fix):** v0.9.0 looked for an installed Exec85 too early on a slow or virtual computer (the disk had not appeared yet), so
  the installer came back. It now waits for the disks to appear before it decides.
- **Minecraft servers list:** Apps > Minecraft server opens on **your servers**: each one with its state and folder. Highlight one and press
  **S** to start, **T** to stop, **R** to restart it, or **E** to accept the EULA. The log line of the highlighted server is shown below the list.
  The same in the terminal: `mc list`, `mc start NAME`, `mc stop NAME`, `mc restart NAME`.
- **Choose where a server is installed:** a new "Install in this folder" box (default `/srv/minecraft`; any folder under `/srv` or `/home`).
  In the terminal: `mc create NAME VERSION 2 --dir /home/me/games`.
- Plus everything from v0.9.0.

### Still missing
Databases, print server, more game servers, scheduled backups, user management, scheduled tasks (v0.9.5); real-hardware testing; a Minecraft allow-list (whitelist) screen.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. A Minecraft server needs more than 2.5 GB of RAM.
