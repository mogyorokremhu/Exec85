**Early alpha: an internet tunnel for connections behind CGNAT (playit.gg).** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.9.2
- **Internet tunnel** (Apps > Internet tunnel, or `tunnel` in the terminal): for a home connection that shares one address between many customers
  (CGNAT), where you cannot forward a port. The playit.gg agent connects *out* to playit.gg, and playit.gg gives you a public address that leads to a port
  on this computer (for Minecraft: 25565). No router settings, no call to your provider, nothing to open in the firewall.
  1. **I** installs it. The two small programs come from the playit.gg project's GitHub release (v2.0.2, BSD licence); the download is pinned and its SHA-256 sums are checked.
  2. **C** gives you a claim link. Open it on a phone or computer and sign up or log in (free).
  3. On playit.gg add a tunnel: "Minecraft Java", local port 25565, and choose a region in Europe if you are offered one.
  4. Players join with the address playit.gg shows you.
  The agent runs as a service under its own `playit` user (starts at boot, restarts if it crashes) and keeps its key in a private folder.
  Terminal: `tunnel install`, `tunnel claim`, `tunnel status`, `tunnel reset` (another account), `tunnel remove`.
- Plus everything from v0.9.1.

### Good to know
- Players' game traffic goes through playit.gg's servers. Keep the Minecraft allow list on (`mc cmd NAME whitelist on`) if the address might spread.
- Which regions playit.gg offers (and which are free) is up to playit.gg; check the ping after the first join. This release only installs and runs the agent.
- The agent version is pinned to v2.0.2; newer versions are not picked up by themselves.

### Still missing
Databases, print server, more game servers, scheduled backups, user management, scheduled tasks (v0.9.5); real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. The tunnel needs an internet connection.
