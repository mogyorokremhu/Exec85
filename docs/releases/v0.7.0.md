**Early alpha: Discord bots, more Minecraft servers, a boot screen and installer music.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.7.0
- **Discord bot installer** (Apps > Discord bot, or `bot` in the terminal): choose **Python** or **Node.js**, then a **starter bot**
  (answers `!ping`), **your own folder**, or a **Git address**. The right runtime and Discord library are installed, the bot's
  **token is typed in a hidden box and kept in a private file** only the bot can read, and the bot runs as a normal service
  (restarts if it crashes, starts at boot). Tested with a fake token: the real library runs and refuses it.
- **Minecraft server types**: choose **Vanilla**, **Paper** (plugins) or **Fabric** (mods), then the version, then 2, 4 or 8 GB.
  Downloads come from each project's official source and are checked where a checksum is published.
- **Readable results**: long messages in the install apps now wrap over several lines, and the Minecraft "done" screen shows the
  address players should connect to.
- **Boot screen**: shown while the system starts, in the same style as the rest of the system and in your chosen light or dark theme.
  (On a very fast machine it may not show at all, because the system is already up.) The kernel's start-up text is hidden.
- **Installer music**: plays in the installer when the computer has a sound card; **F8** switches it off and on.

### Still missing
Changing network settings from the Network app, Wi-Fi, real-hardware testing, accented letters (shown as a box).
Planned next: more quick installers (website, file sharing, Syncthing, Git server, ad blocker, media server), remote access
(SSH, VPN, Wake-on-LAN, web dashboard), updates, uptime monitor with alerts, Vaultwarden; see docs/PLAN.md.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. A Minecraft server needs more than 2.5 GB of RAM. Installing software and downloading servers need a network connection.

### Note about the installer music
The music file is a temporary, third-party placeholder (see `image/assets/audio/README.md`). It will be replaced before the project is made public.

### Verified by CI before this release
BIOS and UEFI, real key presses: everything from v0.6.0, plus real downloads of Paper and Fabric servers (checked, with their plugins/mods folders),
Python and Node.js Discord bots installed for real and refusing a fake token, a private token file, the boot screen starting and getting out of the way,
and the installer music playing (with a virtual sound card) and switching off and on with F8.
