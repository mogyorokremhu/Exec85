**Early alpha: fixes for the install loop, the music and Minecraft, home folders, a browser and more.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.9.0
- **No more installing again and again.** If the install disc is still in the drive, the installer now finds the Exec85 that is already installed and
  **starts it by itself after 10 seconds** (any key stops the countdown; **R** reinstalls, which erases the disk). The computer's boot order no longer matters.
- **Music**: a quieter file (the old one clipped on some sound cards), one fixed volume at every start, a bigger buffer, and never two players at once.
  Together these fix the distortion that grew with every restart.
- **Minecraft**: the done screen now shows what the server is doing from its own log (starting, preparing the spawn area 43%, running, or why it failed:
  EULA, out of memory, port in use ...). It warns when the chosen memory does not fit into the memory that is free right now (the live disc keeps its files
  in memory). `mc status NAME` does the same in the terminal.
- **Home folders**: every user has `Documents`, `Downloads`, `Music`, `Pictures`, `Videos` and `Desktop`. The Desktop is a folder of **shortcuts**
  (small `.shortcut` files: Enter opens the folder or app they point to). `get` saves into `Downloads`.
- **Browser** (Apps > Browser, or `browse ADDRESS` in the terminal): its own small page reader (headings, links, lists, tables, code) and downloads.
  **It only opens allowed sites** (Alpine, Debian, Ubuntu, kernel.org, GitHub, Wikipedia and a few more), over HTTPS, checked again at every redirect.
  An administrator adds a site with **+** or `sites add example.org`. No JavaScript, no pictures, so big modern sites do not work, on purpose.
- **File sharing** (App catalog > File sharing): a Samba share for Windows, Mac and phones, one folder, one user, home network only.
- **Local name** (App catalog > Local name): reach the computer as `NAME.local` on the home network.
- **Disk health** (Apps > Disk health, or `health`): each disk's SMART verdict and temperature and the processor temperature, with warning colours.
- **Log viewer** (Apps > Logs, or `logs`): the kernel and every service's log, with search.

### Still missing
Databases, print server, more game servers (Terraria, Factorio, Valheim, Bedrock), scheduled backups, user management and scheduled tasks: these move to **v0.9.5**.
Also: real-hardware testing, Wi-Fi on real adapters, accented letters (shown as a box). See docs/PLAN.md.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. A Minecraft server needs more than 2.5 GB of RAM. Installing software and downloading need a network connection.
