**Early alpha: updates without reinstalling.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.9.4
- **In-place updates** (Apps > **Updates**, or the `update` command). An update replaces **only Exec85's own files** (the program, boot scripts, the kernel when it changed).
  Your settings, accounts, services, firewall, game servers and everything in the home folders are never touched, and nothing is reinstalled.
- **Two sources:** a file on a USB drive (`exec85-update-v0.9.x.tar.gz` from the GitHub release; press **P**), or straight from GitHub (press **U**). The project is private, so
  GitHub needs an access key: create a fine-grained token (only this repository, **Contents: read-only**) and paste it with **T**. Downloads are checked against the release's SHA-256 sums.
  The computer also looks for a newer version by itself every 6 hours when a key is set (it only tells you; it never installs by itself).
- **Safe by design:** the previous version is kept. After an update the boot menu shows for 3 seconds with an extra entry **"Exec85 (previous version)"**. If the new version runs well for 2 minutes
  it becomes final and the menu hides again. `update rollback` (or **R** in the app) and `update previous` (start the old version at the next boot) go back.
- Restart afterwards (File > Restart) to run the new version.
- Plus everything from v0.9.3.

### Important: the first time
Installed systems from v0.9.3 and older have no update program. **Install v0.9.4 once from the ISO** (on your laptop). Every later version can then be applied in place.
