**Early alpha: a photo and video gallery for the family.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.8
- **Photo and video gallery** (Apps > **Photo gallery**, or the `gallery` command). Keep your pictures and videos in one folder on the server (put them there from the file manager, a USB stick, the browser, or file sharing), and a web page shows **only that folder** (and its subfolders):
  - **You choose the folder** (under /home, /srv, /media, /mnt or /data) with **F**. The page runs as the folder's owner, never as root.
  - **Only pictures and videos** are ever shown or sent (jpg, png, gif, webp, avif, bmp; mp4, m4v, webm, mov, ogv). Notes, documents and every other file stay private. A shortcut (link) inside the folder that leads somewhere else shows nothing.
  - **Its own password** (press **P**, at least 8 characters), so family can look without an account on this computer. Five wrong passwords lock it for five minutes.
  - **Encrypted** (HTTPS on port 8445; your browser warns once that the certificate is not trusted because the server made it itself: continue). The firewall opens the port for your **home network only**; from outside your home use a playit.gg TCP tunnel for port 8445 to `127.0.0.1`, like for the other web pages.
  - **Nice to use:** a grid of thumbnails, folders, a full-screen viewer (arrow keys or swipe), videos that you can skip through, and a Save button. Works on phones.
  - **Adding from the browser** is **off** until you press **U**; then people with the password can add pictures and videos (never overwriting an existing one).
- Plus everything from v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).

### Still missing
Databases, print server, more game servers, scheduled backups, user management, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
