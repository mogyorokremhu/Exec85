**TESTING build (pre-alpha), not for real use.** Same code as v0.7.0, plus a "Skip installation" choice on the installer's Disk step,
so you can try everything **without a disk to erase**. Settings and account are made in memory only and are lost when you shut down.

Try it in QEMU (Windows), no disk needed (the file is named `exec85-v0.7.0-testing.iso`; the extra options give it sound):
```
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 4096 -smp 2 -cdrom exec85-v0.7.0-testing.iso -boot d -vga std -accel tcg -nic user -audiodev dsound,id=snd0 -device intel-hda -device hda-duplex,audiodev=snd0
```
On the Disk step choose **Skip installation**, confirm, log in, then press **Alt+A** for the apps: **Discord bot**, **Minecraft server**, **Services**, **Software** ...
The installer plays music if it has sound (F8 turns it off). The skip choice will be removed later; see docs/TESTING-ONLY.md.
