**Early alpha: change your password, and a clearer Updates screen.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.9
- **`passwd` works now.** Type `passwd` in the Terminal to set a new password for yourself (or `passwd NAME` for another user; you must be an administrator). It asks twice, nothing shows while you type, and the password needs at least 8 characters. This matters for the **browser page** (Apps > Remote access > **W**): it logs in with your normal user name and password and refuses an empty password. Before this version the system's own `passwd` did not work.
- **Updates screen:** it no longer says that a GitHub access key is needed. The project is public, so updates download without one.
- Plus everything from v0.9.8 (photo gallery), v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).

### Still missing
Databases, print server, more game servers, scheduled backups, a full user management screen, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
