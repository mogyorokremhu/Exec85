**Early alpha: an "everyday server" release: firewall, SSH, network settings, Wi-Fi and an App catalog.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.8.0
- **Firewall** (`fw` in the terminal): on by default, everything from outside is blocked except what you open. Services you add can
  declare their ports ("Open ports to the home network"); you can also open a port by hand, for the home network only or for anywhere.
- **SSH server** (Apps > Remote access, or `exec85 --ssh`): log in from another computer. Key-only by default, no root login, and
  you can allow a password if you want. Your public key is checked before it is accepted.
- **Network settings and Wi-Fi** (Apps > Network): automatic (DHCP), a fixed address, or off, per network card; scan for Wi-Fi networks
  and connect. The Wi-Fi password is never stored, only the key made from it. Applied at boot.
- **App catalog** (Apps > App catalog, or `app` in the terminal): one list of what you can install. Quick installers fill in a small form and
  do the rest: **Website** (nginx, serving a folder), **Syncthing** (folder sync, web page protected by a password) and
  **Transmission** (torrents, web page protected by a password). Each opens its port in the firewall for the home network only.
  The bigger ones (Minecraft server, Discord bot) open from the same list.
- **Minecraft**: the EULA is an explicit tick box (off by default) and messages are clearer.
- **Fixes**: the screen now updates in VirtualBox and other virtual or USB displays (the display driver is told when a picture changes);
  programs whose start script needs "net" (nginx and others) can now start; the services' log files belong to the service's user.
- **Installer music**: new original music made for Exec85 (loops until the installer finishes). F8 still switches it off and on.

### Still missing
Samba file sharing, databases, print server, more game servers (Terraria, Factorio, Valheim, Bedrock), `exec85.local`, disk health,
scheduled backups, user management, scheduled tasks and a log viewer: these move to **v0.8.5**. Also: real-hardware testing, Wi-Fi on real
adapters (only the settings and the password maths are tested), accented letters (shown as a box). See docs/PLAN.md.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. A Minecraft server needs more than 2.5 GB of RAM. Installing software and downloading servers need a network connection.

### Verified by CI before this release
BIOS and UEFI, real key presses: everything from v0.7.0, plus the firewall (a blocked port is unreachable from outside, an opened one answers, and closes again),
the SSH server (a key login works, a password login is refused), fixed and automatic network settings, and the catalog installers for a website, Syncthing and Transmission,
each installed for real and answering.
