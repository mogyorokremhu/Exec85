**TESTING build (pre-alpha), not for real use.** Same code as v0.6.0, plus a "Skip installation" choice on the installer's Disk step,
so you can try everything **without a disk to erase**. Settings and account are made in memory only and are lost when you shut down.

Try it in QEMU (Windows), no disk needed (the file is named `exec85-v0.6.0-testing.iso`):
```
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 4096 -smp 2 -cdrom exec85-v0.6.0-testing.iso -boot d -vga std -accel tcg -nic user
```
On the Disk step choose **Skip installation**, confirm, log in, then press **Alt+A** for the apps. To try a pendrive in QEMU, add
`-device qemu-xhci -drive if=none,id=usb,file=stick.img,format=raw -device usb-storage,drive=usb` to the command.
The skip choice will be removed later; see docs/TESTING-ONLY.md.
