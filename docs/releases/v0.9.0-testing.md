**TESTING build (pre-alpha), not for real use.** Same code as v0.9.0, plus a "Skip installation" choice on the installer's Disk step,
so you can try everything **without a disk to erase**. Settings and account are made in memory only and are lost when you shut down.

In **VirtualBox**: type Linux / Other Linux (64-bit), **6 GB RAM** (a live disc keeps its files in memory), I/O APIC on, **Enable EFI off** for the simplest start,
audio controller Intel HD Audio, and virtualization (VT-x / AMD-V) switched on in the computer's BIOS. In QEMU (Windows), no disk needed:
```
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 6144 -smp 2 -cdrom exec85-v0.9.0-testing.iso -boot d -vga std -accel tcg -nic user -audiodev dsound,id=snd0 -device intel-hda -device hda-duplex,audiodev=snd0
```
On the Disk step choose **Skip installation**, confirm, log in, then press **Alt+A** for the apps: **Browser**, **App catalog**, **Logs**, **Disk health**, **Minecraft server** ...
The installer plays music if it has sound (F8 turns it off). The skip choice will be removed later; see docs/TESTING-ONLY.md.
