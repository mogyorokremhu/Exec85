**Early alpha: run your own programs as services, and install software.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.5.0
- **Services app** (Apps menu): add any program as a service by giving its command, folder, user and variables.
  It restarts by itself if it crashes, starts at boot, and keeps running with nobody logged in. Start, stop,
  restart, edit, remove and read its log.
- **Software app**: search for programs, install, remove and update them (uses Alpine's package manager `apk`).
- A small privileged **helper** does the root-only work, for administrators only, accepting a fixed list of actions.
- From a terminal: `exec85 --svc add NAME -- COMMAND`, `exec85 --svc start NAME`, `exec85 --pkg add PACKAGE`, and so on.
- Nothing is built in for any particular program (Minecraft, bots, web servers): they are all just services.

### Still missing
Changing network settings from the Network app, Wi-Fi, accented letters (shown as a box).

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. Installing software needs a network connection.

**Note:** the live disc keeps its files in RAM (about 40% of it is usable), so large programs such as Java need several GB of RAM to install *from the live disc*. An installed system uses the disk and has no such limit.

### Verified by CI before this release
BIOS and UEFI, real key presses: a web server defined as a service is killed and comes back with a new process; nginx and Python installed with `apk` and answering; a service started on an installed system is still running after a restart with nobody logged in; the Services and Software apps show real data.
