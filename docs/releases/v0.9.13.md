**Early alpha: block your own sites in the ad blocker.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.13
- **Your own block list** in Apps > **Ad blocker**: press **B** and type a site's name (for example `games.example.com`) to block it **with all its subdomains**, for every device that uses this computer as its DNS server. **X** unblocks it again. The names you blocked show on the screen. Command line: `adblock block NAME` and `adblock unblock NAME`.
- A name you block on purpose is taken off your allowed list; **C** (check) tells you when a name is blocked by you.
- Plus everything from v0.9.12 (ad blocker), v0.9.11 (Tailscale fix), v0.9.10 (Tailscale, importing a Minecraft server), v0.9.9 (`passwd`), v0.9.8 (photo gallery), v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).

### Still missing
A QR code for the Tailscale sign-in, databases, print server, more game servers, scheduled backups, a full user management screen, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
