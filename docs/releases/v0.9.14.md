**Early alpha: import big block lists into the ad blocker.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.14
- **Import lists** in Apps > **Ad blocker**: press **I** and give either
  - the **path of a list file** on this computer (under /home, /srv, /media, /mnt or /data: put it there from the file manager, a USB stick, the browser page or file sharing), or
  - the **address of a list on the web** (https://...).
  - Hosts files (`0.0.0.0 name`), plain lists (one name per line) and adblock lists (`||name^`) are understood; comments and other lines are ignored. Big files are read one line at a time.
  - Lists from the web are fetched again when you press **U** (update). **K** removes a list. The **Lists** line shows each list and how many names it has. Command line: `adblock import FILE-or-https://ADDRESS [NAME]`, `adblock unimport NAME`.
- **A limit that protects the computer:** the DNS server keeps every name in memory (about 150 bytes each), so the ad blocker holds at most what fits in a quarter of the memory, for example about 1.7 million names on a 1 GB computer and about 14 million on 8 GB. The screen shows "Room for ..." and an import that would go over is refused with nothing changed. Tens of millions of names do not fit on any home computer; the big public lists have a few hundred thousand to a few million.
- Allowed names (**A**) are also taken out of imported lists; your own blocks (**B**) stay.
- Plus everything from v0.9.13 (block your own sites), v0.9.12 (ad blocker), v0.9.11 (Tailscale fix), v0.9.10 (Tailscale, importing a Minecraft server), v0.9.9 (`passwd`), v0.9.8 (photo gallery), v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).
