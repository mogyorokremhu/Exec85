**TESTING build (pre-alpha), not for real use.** Same code as v0.5.0, plus a "Skip installation" choice on the installer's Disk step,
so you can try everything **without a disk to erase**. Settings and account are made in memory only and are lost when you shut down.

Try it in QEMU (Windows), no disk needed (the file is named `exec85-v0.5.0-testing.iso`):
```
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 1024 -smp 2 -cdrom exec85-v0.5.0-testing.iso -boot d -vga std -accel tcg -nic user
```
On the Disk step choose **Skip installation**, confirm, log in, then open Services or Software from the Apps menu (Alt+A).
The skip choice will be removed later; see docs/TESTING-ONLY.md.
