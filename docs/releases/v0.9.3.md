**Early alpha: fixes for the internet tunnel download and for the install disc coming back.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.9.3
- **Internet tunnel install (fix):** the download failed with "curl: (6) Could not resolve host" on VirtualBox's NAT network. curl has its own name lookup,
  which does not work there. The tunnel programs are now downloaded with the system's own downloader (the one the Minecraft and Java downloads use); their
  SHA-256 sums are still checked. The **browser** now also hands curl an address found by the system's lookup, so it does not depend on curl's own.
- **Install disc left in the drive (more robust):** the check for an installed Exec85 now waits longer for the disk to appear when the computer has a disk controller
  (up to 20 seconds, for slow virtual machines without hardware virtualization), waits for the partitions to be read, and does not wait long when there is nothing to wait for.
  If an installed Exec85 still shows up while the Welcome screen is open, the screen now says so and how to start it (restart and take the disc out).
  CI has a new test where the installed disk is plugged in 8 seconds after boot.
- **No more testing ISO releases:** only the normal ISO is published (the testing ISO is used inside the automatic tests only). Try everything in VirtualBox with the normal ISO.
- Plus everything from v0.9.2.

### If the install disc still comes back in VirtualBox
Take the disc out after installing: Settings > Storage, remove the ISO, or untick **Optical** in Settings > System > Boot Order. Send me the VM's log (Machine > Show Log) if it still happens with the new version.

### Still missing
Databases, print server, more game servers, scheduled backups, user management, scheduled tasks (v0.9.5); real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. The tunnel and the browser need an internet connection.
