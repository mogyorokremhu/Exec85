**Early alpha: pendrives, our own terminal commands, a Minecraft server helper and sleep mode.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines only, **not yet on real hardware**.

### What's new in v0.6.0
- **Pendrives.** Plug in a USB drive and it appears in the Explorer's drive row by itself (FAT32, exFAT, NTFS and
  Linux drives). Copy, cut, delete, rename and edit files on it. **E** in the drive row, or **File > Eject drive**,
  removes it safely. Pulling it out without ejecting is noticed too. Programs on a drive cannot be run from it.
- **Our own terminal commands** (in the Terminal app): `help`, `dir`, `disk`, `about`, `get`, and the short forms
  `svc`, `pkg` and `mc`. The normal commands (`ls`, `cat`, `grep` ...) all still work.
- **Minecraft server helper** (Apps > Minecraft server, or `mc` in the terminal): choose a version from Mojang's list,
  **2, 4 or 8 GB** of memory (only sizes that fit your computer), and tick the EULA box (off by default, nothing is
  accepted for you). The server is downloaded from Mojang and its checksum is checked, the right Java is installed
  (from Alpine, or Eclipse Temurin when Alpine does not have it yet), and the server runs as a normal service.
- **Sleep mode.** **F8** (or View > Sleep now) turns the screen off; programs and services keep running. A key press
  wakes it (and is not used for anything else). View > "Sleep after ..." sets an automatic timer.

### Still missing
Changing network settings from the Network app, Wi-Fi, real-hardware testing, accented letters (shown as a box).

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**. A Minecraft server needs a computer with more than 2.5 GB of RAM
(more for 4 or 8 GB). Installing software and downloading a server need a network connection.
**Note:** the live disc keeps its files in RAM, so large downloads there need several GB of RAM. An installed system has no such limit.

### Verified by CI before this release
BIOS and UEFI, real key presses and a virtual USB stick: plug in, read, write, copy, delete, eject, pull out and plug in
again; each of our terminal commands; the real Minecraft server download from Mojang with a checksum check, Java and the
server program starting as a service (with and without the EULA tick); sleep mode (black screen, a running website keeps
answering, a key wakes the screen); plus everything from v0.5.0.
