**Early alpha: you can now install Exec85 on a disk and log in.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** It has been tested in virtual machines
> (BIOS and UEFI) but **not yet on real hardware**. Do not point it at a disk you care about.

### What works
- A keyboard-driven **installer**: light or dark mode, keyboard layout (US, UK, German, Hungarian),
  time zone, device name, user name, optional password, disk choice, and a final confirmation where you
  must type the disk's name.
- GPT disk layout that boots on **BIOS and UEFI** and handles disks over 2 TB.
- A **login screen** on every start. The file-browser shell then runs as **your user, not root**.
- Everything from v0.2.0: menu bar, drive row, arrow-key file list, tiled windows, light/dark theme.

### What is not there yet
Apps (Notepad, terminal, ...), the service manager, software installation, networking settings, Wi-Fi
firmware. Accented letters (such as the Hungarian o with double acute) are typed correctly but display as a box.

### Requirements
- x86-64 PC, BIOS or UEFI.
- **At least 1 GB of RAM to run the installer**: the install image runs entirely from memory. (A 512 MB
  machine fails to start it. This will be reduced in a later release.) The *installed* system needs far
  less: about 150 MB used at idle in the test VM.

### Try it in QEMU (Windows)
```
& "C:\Program Files\qemu\qemu-img.exe" create -f qcow2 exec85-disk.qcow2 16G
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 1024 -smp 2 -cdrom exec85-v0.3.0.iso -boot d -drive file=exec85-disk.qcow2,if=ide -vga std -accel tcg
```
Choose **Install Exec85**, follow the steps, restart, then start it again from the disk only (no CD):
```
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 1024 -smp 2 -drive file=exec85-disk.qcow2,if=ide -vga std -accel tcg
```
Check the download with `sha256sum -c SHA256SUMS`.

### Verified by CI before this release
The release was built from scratch and tested in QEMU on both BIOS and UEFI by pressing real keys: a full
install onto an empty virtual disk, a restart *from that disk*, a wrong then a right password at the login
screen, the shell running as an unprivileged user, and logging out. Numbers are in docs/MEASURING.md.
