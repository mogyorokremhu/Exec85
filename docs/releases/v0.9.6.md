**Early alpha: screen brightness.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.6
- **Brightness** for the screen: **F12** brighter, **F11** darker (and the laptop's own brightness keys, Fn + the sun symbols, work too), or View > **Brighter / Darker / Brightness 100%, 70%, 40%, 20%**. Steps of 10 percent, never fully dark. The command `brightness 60` does the same from a terminal, and `brightness` shows the setting.
- **Real backlight first:** on a laptop with a backlight, the real backlight is set (`/sys/class/backlight`). When there is none (a desktop screen, a virtual machine), the picture itself is darkened. The setting is remembered across restarts.
- **In the browser:** F11 / F12 in a browser session change the brightness of the server's own screen.
- Plus everything from v0.9.5 (browser access, the Paper fix).

### Still missing
Databases, print server, more game servers, scheduled backups, user management, scheduled tasks, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
