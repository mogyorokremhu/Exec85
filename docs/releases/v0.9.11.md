**Early alpha: Tailscale fix.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.11
- **Tailscale starts after an in-place update.** In v0.9.10 the Tailscale service failed to start on a system that was updated (not freshly installed): a small start file was not part of the update, and the service name clashed with Alpine's own init script. Now the start file is written when you press **I** in Apps > Tailscale, the service has its own name, and the error message no longer hides the real reason behind harmless notes about base-system services. If you pressed **I** in v0.9.10, just press **I** again.
- Plus everything from v0.9.10 (Tailscale, importing a Minecraft server), v0.9.9 (`passwd`), v0.9.8 (photo gallery), v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).

### Still missing
A network-wide ad blocker (next), databases, print server, more game servers, scheduled backups, a full user management screen, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
