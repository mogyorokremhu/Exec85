**TESTING build (pre-alpha), not for real use.** Same code as v0.4.0, plus one extra choice in the installer so you can try the
whole system **without a disk to erase**.

On the **Disk** step, the first choice is **Skip installation**. Nothing is installed or erased: your theme, keyboard, time zone,
device name and account are set up in memory only, then you get the login screen and the shell with all the apps. **Everything is lost
when you shut down.**

### Try it in QEMU (Windows), no disk needed
```
& "C:\Program Files\qemu\qemu-system-x86_64.exe" -m 1024 -smp 2 -cdrom exec85-testing-v0.4.0-testing.iso -boot d -vga std -accel tcg
```
Pick the settings, choose **Skip installation** on the Disk step, press Enter to confirm, then log in with the password you chose.
For the real thing, use the normal release (`v0.4.0`). This skip choice will be removed later; see docs/TESTING-ONLY.md.
