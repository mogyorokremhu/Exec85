**Early alpha: Tailscale (a private network for your own devices) and importing an existing Minecraft server.** Try it in a virtual machine first.

> **Warning: the installer erases the whole disk you choose.** Tested in virtual machines and on one laptop, **not yet widely on real hardware**.

### What's new in v0.9.10
- **Tailscale** (Apps > **Tailscale**, or the `vpn` command). A free private network between your own devices (phone, PC, this server), reachable from anywhere, with nothing opened to the internet:
  - **I** installs it (from Alpine's packages; the computer must be online), **L** starts the sign-in: it shows an address you open on any phone or PC and log in with your Tailscale account. Install the free Tailscale app on your phone or PC and sign in with the same account.
  - Then the server has a private address (100.x.y.z) that works from all your devices: `https://<address>:8443` for the screen in a browser, the gallery, files, and so on.
  - The firewall treats Tailscale like your home network (only for the rules that are meant for the home network). Everybody on your Tailscale network gets that access, so only invite people you trust.
  - **O** signs out, **X** switches it off.
- **Importing a Minecraft server you already have** (`mc import NAME FOLDER RAM`). Copy the server folder to your disk (no spaces in the folder name, under /home or /srv), then for example: `mc import survival /home/you/Documents/minecraft_server 4`. It finds the server file (server.jar or paper-26.3-45.jar and so on), picks the right Java from the version (26.x: Java 25, 1.21: Java 21, ...), reads the port from `server.properties` and starts it as a service that comes up after a restart. It warns when another server already uses the same port.
- **Imported servers show up** in Apps > Minecraft server and take console commands (`mc cmd NAME whitelist add friend`), also when the server file is not called server.jar.
- Plus everything from v0.9.9 (`passwd`), v0.9.8 (photo gallery), v0.9.7 (website monitor), v0.9.6 (brightness) and v0.9.5 (the screen in a browser, the Paper fix).

### Still missing
A network-wide ad blocker (next), databases, print server, more game servers, scheduled backups, a full user management screen, an automatic-update option; widespread real-hardware testing.

### Requirements
x86-64, BIOS or UEFI, **1 GB RAM for the installer**.
