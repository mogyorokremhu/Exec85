# Installer music

`installer.mp3` is background music for the installer. It is original music written for Exec85 (generated by the
scripts in `source/`: `make_three.py` holds the instruments, `make_b2.py` makes this track, "B3"), so there is no
third-party copyright on it. It is about 23 seconds long and made to loop without a gap; the installer's player
repeats it for as long as the installer runs.

The installer plays any file named `installer.mp3` here, so replacing it is just a file swap.
